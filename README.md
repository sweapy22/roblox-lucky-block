# Roblox Lucky Block

Shared project repository for our Roblox Lucky Block game.

## Current Studio project

Place ID: `108916702760480`. Inspected through Studio MCP on 2026-10-17.

- Eight bases with domes, podiums, entrances, and arrows.
- Eight bridges, eight player spawn markers, and nine lucky-block spawn markers.
- Central platform with paths, trees, lucky-block pads, a podium, fountain, and lamps.
- Lighting effects and a DomeTemplate in ServerStorage.
- No gameplay scripts were present at inspection time.

The Studio place and project files have not been uploaded yet. This repository does not automatically sync with Roblox Studio.

## Join the project

1. Give the repository owner your GitHub username.
2. The owner opens Settings > Collaborators > Add people and invites you.
3. Accept the GitHub invitation.
4. Sign into GitHub Desktop with your own account.
5. Choose File > Clone repository, select sweapy22/roblox-lucky-block, and choose a local folder.

## Add the existing project

Clone this repository first. Copy the game project files into that local repository folder, preserving their folder structure. Save a local copy of the Studio place into a `places/` folder. Review the changed files in GitHub Desktop, commit them, then Push origin. Do not add passwords, API keys, or unrelated personal files.

## Work together

- Fetch origin and pull changes before starting work.
- Create a branch for a feature, make changes, commit with a clear message, and push the branch.
- Open a pull request and have a teammate review it before merging.
- Coordinate ownership of saved place files: Git cannot safely combine simultaneous edits to a binary `.rbxl` file.
- GitHub access and Roblox Studio collaboration access are separate.

## Suggested folders

- `places/`: saved Roblox places
- `src/`: exported Luau scripts when a script workflow is established
- `assets/`: source art, audio, and models
- `docs/`: game design and team notes

These folders are a proposed layout, not an existing Studio synchronization configuration.
